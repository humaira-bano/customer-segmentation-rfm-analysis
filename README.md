# Customer Segmentation & RFM Analysis

## Project Overview

This project analyzes customer data using RFM (Recency, Frequency, Monetary) analysis to understand customer behavior and segment customers based on their purchasing patterns.

## Tools & Technologies

- Microsoft Excel
- RFM Analysis
- Data Analysis
- Data Visualization

## Analysis Performed

- Total customer analysis
- Customer segmentation
- Recency analysis
- Frequency analysis
- Monetary value analysis
- Revenue by customer segment
- Customer segment distribution
- Dashboard visualization

## Customer Segments

The customers were divided into five segments:

- High Value
- Loyal Customer
- Potential Customer
- New Customer
- At Risk

## Key Insights

The analysis helps identify valuable and loyal customers, potential customers, new customers, and customers who may be at risk of becoming inactive.

RFM analysis provides a useful way to understand customer purchasing behavior and support data-driven customer retention and marketing decisions.
